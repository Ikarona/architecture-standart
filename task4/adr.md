### Название задачи:
Передача актуальных ставок в кол-центр банка и партнёрский кол-центр (MVP)

### Автор:
Команда цифровой трансформации

### Дата:
2025-09-09

### Функциональные требования (Use Cases)

| № | Акторы / Системы | Use Case | Описание |
|:-:|:-|:-|:-|
| UC1 | Бэк-офис депозитов, Бэк-офис кредитов, Rates Admin UI | Ведение ставок | Создание/редактирование ставок, разграничение прав (депозиты/кредиты), версии и сроки действия. |
| UC2 | Система кол-центра банка, Rates API | Онлайн-доступ к ставкам | Запрос актуальных ставок оператором КЦ банка через API; локальный кеш и автообновление. |
| UC3 | Partner Exporter, Почтовая служба банка, Партнёрский КЦ | Доставка файлов партнёру | Периодическая генерация подписанных CSV/JSON со ставками и отправка по электронной почте. |
| UC4 | Rates Platform | Аудит и журнал изменений | Хранение истории изменений ставок, просмотр версии, восстановление. |
| UC5 | Мониторинг | Контроль доставки и актуальности | Отслеживание успешной отправки писем, подтверждения получения, контроль «возраста» ставки для КЦ банка. |

| № | Требование |
|:-:|:-|
| NFR1 | Актуальность: КЦ банка — не хуже T+5 минут; партнёр — не хуже T+1 час. |

| NFR4 | Совместимость со стеком: .NET/Java; MS SQL; интеграция с существующей почтовой инфраструктурой банка. |
| NFR5 | Наблюдаемость: логи, метрики, алёрты по недоставке/рассинхронизации, трассировка запросов API. |

### Решение

Диаграммы: `Task4_C4_Context_Rates.drawio`, `Task4_C4_Components_Rates.drawio`.

Основные компоненты и интеграции всех элементов решения:
- Rates Admin UI: интерфейс для БО депозитов и кредитов (UC1).
- Rates API: чтение актуальных ставок системой КЦ банка (UC2), с кешированием и версионированием.
- Rates Store (MS SQL): хранилище ставок, версии, аудит (UC1, UC4).
- CC Integrator (внутри системы КЦ банка): регулярное обновление кеша из Rates API, индикация «возраста» данных (UC2, UC5).
- Partner Exporter: формирование CSV/JSON, цифровая подпись, вложение в письмо (UC3).
- Почтовая служба банка: отправка писем партнёру по корпоративной почте (UC3).
- Партнёрский КЦ: приём писем, загрузка файлов в свою систему (UC3).
- Мониторинг: контроль статусов доставки и свежести ставок (UC5).

### Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| Рассылка Excel-файлов | Минимум доработок | Нет аудита и версий, человеческие ошибки, слабая автоматизация |
| Хранить ставки в АБС | Централизация | Ограничения масштабирования и сроки изменений |
| Интеграция по SFTP | Устойчивая доставка файлов | Недоступно по условиям партнёра |

### Недостатки, ограничения, риски

| Пункт | Описание |
|---|---|
| Р1 | Зависимость от почтовой доставки: требуется контроль недоставки/повторная отправка. |
| Р2 | Консистентность версий у партнёра: обязательны поля `version`, `valid_from`, `valid_to`. |
| Р3 | Требуется точная настройка ролей и аудита для разделения депозиты/кредиты. |
